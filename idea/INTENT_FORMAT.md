# Intent format

```markdown
# Intent: <the problem, in a few words>

## Problem
<One paragraph: what is wrong and what would be true instead, with no mechanism in it.

Then one instance, in a second paragraph: the last time it happened, what went wrong, what it cost, and how often it recurs. Where there is no instance yet, say that and say why.>

## Proposed outcome
<What is true once this is solved, stated so that anyone could tell whether it holds. Not the mechanism.>

## Affected
<Who feels this problem.>

## Constraints
<What disqualifies a candidate outright - a budget, a deadline, a property that must not break. Each one says what it would kill.>

## Whatever they arrived with
<The solution the user brought. Omit only when they genuinely arrived with a problem.>

## Open questions
<What could not be settled until the field of candidates exists. A question you did not ask does not belong here. Omit the section when there are none.>
```
