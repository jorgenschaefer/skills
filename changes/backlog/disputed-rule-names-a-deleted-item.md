# A disputed rule stops naming a backlog item that is gone

A rule the developer disagreed with at `/init-security-policy` ends with
`*Disputed:*` and the path of the backlog item that would change it
(`SECURITY_POLICY_FORMAT.md`). When `/idea` deletes that item - already
solved, or not worth the work - the rule keeps naming a file that no
longer exists. No skill may clear the mark, because the policy changes
only through a change's Security policy ACs, `/init-security-policy` or a
keep at acceptance.
