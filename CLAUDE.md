This is a suite of skills for creating High Quality Software with coding agents.

MANIFESTO.md states what software built by agents is for, who does what in building it, and why. Every skill serves it; read it before changing what a skill does.

PIPELINE.md says what the pipeline is meant to be: its phases, its stages, the developer's stops and the rules across them. Read it before changing what a skill is for.

A skill only sees files in its own directory, so a file two skills need is copied into each.

README.md says how to install the skills and what the scripts do.

Fast check: `./test.sh`
