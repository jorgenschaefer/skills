This is a suite of skills for creating High Quality Software with coding agents.

SDLC.md says what software development is for, the goals that serve it, and the user journeys of developing with these skills: adding a feature, debugging, refactoring and the backlog. Every skill serves it; read it before changing what a skill does or is for.

A skill only sees files in its own directory, so a file two skills need is copied into each.

README.md says how to install the skills and what the scripts do.

Fast check: `./test.sh`
